## Implementation and audit contract

`production_autopilot` now validates the frozen source/Mask/ROI and previous repair Receipt **before** any native model call. On each generated image it retains:
- `native-generated.png`: the original byte-for-byte Codex native image output; independently checked against original `generated_images` source/copy event.
- `generated.png`: the strictly derived pixel candidate, composed only in approved editable pixels from the native output.
- `precision-compose-report.json`: preservation and exact SHA evidence.
- `packet.json`, `events.jsonl`, `attestation.json`, `receipt.json`: original generation workflow evidence. The Receipt binds the **derived** PNG; the attestation explicitly binds both raw and derived SHA and states that the derived bytes were not directly generated by the model.

`production_audit` independently recomputes all pixels from original source, native output and SHA-pinned approved Mask. It cross-checks input spec SHA, previous repair Receipt, source/master identity, current derived Receipt, critic binding and original native `generated_images` provenance. It rejects tampered mask, raw/derived PNG, compose report or inconsistent receipt/packet/QA. No self-written `PASS` or fake backend can stand in for an actual native Host run.

A SHA-bound numeric ROI precheck is now passed to the readonly model critic, so `visual.region_preservation` need not infer zero drift from eyesight or call tools in its restricted sandbox. Technical pixel PASS **never certifies** seams, materials, identity, artistic merit, rights or Unity; conservative critic FAIL/NOT_VERIFIABLE still blocks acceptance and is persisted faithfully.

Repair rounds use the previous *audited derived* image as their edit target and the immutable original approved Master as support, with both SHA/Receipt verified **before ImageGen**. When source binding is invalid, the generator stops before spending another call.
